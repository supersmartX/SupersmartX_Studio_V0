# SuperSmartX Studio Brand Kit v4 — Production Ready

This package is a cleaned and production-oriented release of the approved Studio identity.

### Included
- Approved canonical Studio mark
- 1024 / 2048 / 4096 high-resolution raster exports
- PNG + SVG-wrapper logo assets
- Monochrome purple/white/black variants
- Favicon and PWA icon set
- Apple touch icon
- Web manifest
- 1200×630 Open Graph image
- Color tokens and CSS variables
- Typography specification
- Logo usage and brand guidelines
- Clear-space and minimum-size rules
- Explicit vector-source note

### Important
The approved source artwork is 1024×1024 raster. The 2048px and 4096px files are high-resolution raster exports generated from that approved source; they do not create additional original detail. The SVG asset is a scalable wrapper around the exact approved PNG, not a native editable vector.

For future print identity work, commission a manual vector trace from the approved artwork and visually approve it before replacing the current master.
