# SuperSmartX Studio — Logo Usage

## Canonical mark
Use the approved ribbon/film-strip S + play mark supplied in this kit.

## Do
- Preserve the artwork exactly.
- Maintain at least 25% of the mark width as clear space on every side.
- Use the supplied transparent PNG/SVG wrapper assets.
- Use the supplied monochrome versions when a one-color treatment is required.
- Keep the mark optically centered.

## Don't
- Do not redraw or simplify the mark.
- Do not stretch, skew, rotate, crop, outline, or recolor it.
- Do not add shadows, glows, gradients, or effects to the canonical logo.
- Do not place it on a background that destroys legibility.

## Minimum size
- Preferred: 24px or larger in UI.
- Absolute minimum: 16px for favicon/tiny UI contexts.
- For print, use the 4096px master where raster artwork is required.

## Vector note
The supplied SVG is a scalable SVG wrapper containing the exact approved raster artwork. It is not a natively editable vector tracing. A true vector master should only replace it after manual tracing and visual approval.
