# SupersmartX Studio documentation

This directory is organized by how the documentation is used:

- `core/` — product, architecture, information architecture, flows and design system.
- `engineering/` — API, database, storage, export and testing contracts.
- `security/` — authentication, authorization, security and data ownership.
- `billing/` — Paddle integration, payment recovery and billing remediation.
- `operations/` — deployment, local development, incident response, rollback and troubleshooting.
- `archive/` — historical audits, phase validation evidence and completed implementation reports.

Start with `core/PRD.md`, `core/ARCHITECTURE.md`, `operations/PRODUCTION-RUNBOOK.md` and `engineering/TEST_PLAN.md`.
